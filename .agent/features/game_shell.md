# 遊戲外殼(game shell)

2026-09-13 定案。取代原本的「偵探證物板 + 長頁捲動」。

## 概念來源

用戶本人的想法,不是 AI 提案:他從剛學會寫 code 起就想做「遊戲合集」——
一個畫面 3x2 格子,每格一個遊戲,點了打開、關掉回來。
網站照這個做:**整個網站是一款遊戲,不是一份文件。**

## 判準(從用戶自己的話與作品收斂)

- 不要「像網頁」。用戶原話:「純色平字會像網頁不像遊戲」(CookTWGame 成就面板註解)。
- 一個畫面,不上下拖曳。分頁切換、過場動畫、按鈕。
- 他在意「功能看起來很順」勝過視覺美術。過場手感要反覆雕。
- 背景不做繪製:他不畫背景圖,過去作品幾乎純黑 + 白線。主體靠版面與動態撐。
- 素材現實:像素 sprite 只有 walker.png(18x30)、yv.png(32x32),作品截圖 10 張是縮圖。
  陳列不能靠圖,靠文案——site.ts 那些一句話是全站最強的資產。

## 視覺規範(取自用戶真手寫的 LittleWitch 與他雕過的成就面板)

- 暖金色系是他的預設:0xFDF3AE→0xF6B853 漸層、0xF0C37D、網站沿用 #e8b463。
- 文字帶深色描邊,round join。純色平字會像網頁。
- 位置用比例不用絕對像素。
- 進場逐項有節奏,不一起出現;動態幅度極小(呼吸 ±0.02)。
- 退場比進場快(成就面板 150ms 進 / 120ms 出,註解:關閉要俐落,不能讓人等)。
- 面板半透明、留邊,底下場景仍看得見——不切斷上下文。
- 一定給鍵盤替代(Esc 關閉、數字鍵選項)。
- 標題襯線,內文無襯線。

## 架構

- 像素世界從「第一段」升格為**常駐主選單背景**。用戶喜歡它的三個理由
  (會動、人物是他畫的、配色不像 AI)原封不動保留。
- 主畫面 = 像素世界 + 標題 + 選單按鈕。
- 分頁:作品 / 繪圖 / 文 / 磚 / 關於,覆蓋在主畫面上,有過場。
- 作品格子點開詳情,Esc 或關閉鈕回格子。
- 全站不捲動;分頁內容超出才在面板內捲。

## 未解

- 工具鏈(自寫打包工具、編譯器、三個編輯器)目前全站沒有位置,
  會把用戶縮小成「做了幾個遊戲的人」。主幹上留一格,內容待補。
- 繪圖在舊版排最後、縮成小膠卷帶,但那是用戶唯一說滿意的作品。
  新版重心待用戶划過原型後決定。
