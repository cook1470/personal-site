# 遊戲外殼（game shell）

2026-09-13 定案。取代原本的「偵探證物板 + 長頁捲動」。

## 概念來源

用戶本人的想法，不是 AI 提案：他從剛學會寫 code 起就想做「遊戲合集」——
一個畫面 3x2 格子，每格一個遊戲，點了打開、關掉回來。
網站照這個做：**整個網站是一款遊戲，不是一份文件。**

## 判準（從用戶自己的話與作品收斂）

- 不要「像網頁」。用戶原話：「純色平字會像網頁不像遊戲」（CookTWGame 成就面板註解）。
- 一個畫面，不上下拖曳。分頁切換、過場動畫、按鈕。
- 設計成不需要捲軸的樣子，內容裝不下就縮排版，不要出捲軸。
- 他在意「功能看起來很順」勝過視覺美術。過場手感要反覆雕。
- 關閉要俐落：不做退場動畫，直接收掉。
- 背景不做繪製：他不畫背景圖，過去作品幾乎純黑 + 白線。主體靠版面與動態撐。
- 素材現實：像素 sprite 只有 walker.png（18x30）、yv.png（32x32），作品截圖 10 張是縮圖。

## 文字與符號

- 中文句子不用半形 `,` `:`，一律全形。這條也適用 code 註解、.agent 文件、commit 訊息。
- 不用 `→` `←` 這類箭頭符號，用戶原話：「超級 AI，只有 Claude 會用那東西」。

## 視覺規範

網站字體與標題樣式維持原樣（深藍 #1d3a5f + 白色偏移陰影），不要換襯線、不要加文字描邊——
CSS 的 text-stroke 往內吃字，跟 Pixi 的外擴描邊不是同一回事，小字會直接糊掉。

- 暖金 #e8b463 / #f0c37d 是面板與強調色。
- 進場 150ms cubic-bezier(.2,.9,.3,1.1)，關閉不做動畫。
- 面板半透明、尺寸依內容給，背後一律半透明黑遮罩，點遮罩可關。
- 一定給鍵盤替代（數字鍵開頁、Esc 關閉）。

## 架構

- 像素世界從「第一段」升格為常駐主選單背景。用戶喜歡它的三個理由
  （會動、人物是他畫的、配色不像 AI）原封不動保留。
- 主畫面 = 像素世界 + 標題 + 選單按鈕。
- 分頁：作品 / 繪圖 / 文 / 磚 / 關於，覆蓋在主畫面上。
- 作品格子點開詳情（左圖右文），Esc 或返回鈕回格子。

## 未解

- 工具鏈（自寫打包工具、編譯器、三個編輯器）目前全站沒有位置，
  會把用戶縮小成「做了幾個遊戲的人」。留一格，內容待補。
- 繪圖在舊版排最後、縮成小膠卷帶，但那是用戶唯一說滿意的作品。
  新版重心待用戶划過原型後決定。
