# 創作者輪廓(網站設計依據)

2026-08-11 由四個研究代理人掃過 11 個專案(phantasia-engine、VisualNovelEngine、Fabula、PhantomLedger、Ryvexia、Dunjo、GojuuonBingo、LittleWitch、PixiTank、CK_TWEventsGame、CookTWGame)歸納而成。網站的視覺與文案方向以此為準。

## 品牌身分(2026-08-11 用戶拍板)

- 名義統一為「酷可 / cook」,DC、MC、X、YT 皆同名,聯想已存在,網站收攏它們。
- 「幻/Phanta-」系命名是 AI 幫專案取名的慣性,只代表專案,不代表本人,不當品牌。
- 工作室名留待以後自然長出,不卡進度。

## 核心身分

不是「做了很多遊戲的人」,是「在建一個能持續產出遊戲的個人工作室」。
作品廣度極寬(音game、平台跳躍、塔防、殭屍生存、RTS、TRPG、視覺小說、教育小品、多人對戰),但全部收斂在 2D + TypeScript + 自建系統這條主幹上。

## 五個最有辨識度的特質

1. 把限制當設計素材:Gemma 免費額度→多模型分工;AI 額度爆掉→六角色成本分級;
   CG 平台無預覽→合理預設值減害;沒美術→全程 Graphics 自繪並統一灰階。
2. 造工具癖/讓別人也能創作:五個作品裡三個內建完整編輯器(譜面、關卡、地圖,
   都有 Undo/Redo);兩代視覺小說引擎;目標受眾常是「不會寫程式的創作者」。
3. AI 是班底不是工具:Fabula 把 LLM 拆成導演/編劇/NPC 心理;PhantomLedger 把
   開發拆成六個 AI 角色;文件寫給 AI 看(.agent 文化、README 常是樣板沒改)。
4. 機制先於文字,但文字寫得很好:「這是遊戲不是互動式小說」;人格不給數字、
   揭示只發生一次;「台詞即儀表板」。散文能力強但主動為玩法讓路。
5. 對社群的歸屬與回饋:開源模組、30 天教學、教學影片、Discord 社群、
   素材授權逐條列出;技術一絲不苟,對外講話親切有台語梗。

## 美術調性(跨專案一致)

- 暗底、細線、單色系、單一克制的強調色、拒絕裝飾性特效。
- 具體案例:Ryvexia 賽博龐克(青/洋紅/黃 on 近黑、切角不用圓角);
  Dunjo 純黑白灰階;PhantomLedger 半透明深底+金色細線框;
  phantasia-engine 單一強調色 #e8b463、明令不用 uppercase/tracking(中文無效);
  Fabula 終端機風、後期方向是清掉 glow 往冷靜收斂。
- 共同鐵律:禁 emoji 當圖示、色弱友善(色相外加第二維度)、
  「一個好的預設」勝過無限彈性、反欄位牆。

## 命名品味

自創複合詞與敘事感命名:Ryvexia(Rhythm+Vex)、Fabula(拉丁文「故事」)、
PhantomLedger/幻錄、Phantasia、Dunjo、《小女巫・啟程》、石秤、樹畔。
偏好「Phanta-」「幻」系語感。

## 文字風格

極短句、只寫看得到的東西、不解釋:「路基石像沒埋完的骨」「煙就是路牌」。
「當題材是死的,當質地是活的」。網站文案應照此風格寫,不用形容詞堆砌。
